# **Arbitrage-Consistent Neural Smoothing of the Implied Volatility Surface**

This repository contains the code used for the MSc thesis:

Euan Bronsky (2026), *Arbitrage-Consistent Neural Smoothing of the Implied Volatility Surface: A State-Space Approach*

**Overview**

The code covers (in chronological order):

1. Cleaning SPX option data and enforcing no-arbitrage restrictions
2. A preliminary analysis to summarize the data used
3. Estimating the various model specifications
4. Enforcing the no-arbitrage restrictions for the smoother model
5. Evaluating the various models out-of-sample
6. Robustness check using a rolling window estimation procedure
7. Density forecasting and Value-at-Risk backtest

**Requirements**

The project was run with:

- Python 3.14.2
- Operating system: macOS Tahoe 26.5.1 
- Main packages: numpy, pandas, scipy, pytorch, statsmodels, matplotlib

## **Data**

The raw SPX option data are not included because they are obtained from OptionsDX and are subject to data-access restrictions.

The analysis also uses:

- U.S. Treasury Par Yield Curve Rates
- S&P 500 dividend-yield data

## **Outputs**

The scripts generate:

- Cleaned datasets
- Model estimates and forecasts
- Forecast-evaluation results
- Arbitrage violation results
- Tables and figures used in the thesis

## **Reproducibility**

Full replication requires access to the same raw OptionsDX data and external rate and dividend-yield datasets, as well as the exact same seeds used in the code files.
